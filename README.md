# Movie Forum (Node.js Web App)

## Link

https://movie-forum.onrender.com/quizzes

## Overview

**Movie Forum** is a **Node.js* Web app that allows movie fans to find quizzes and test their knowledge on their favorite films. 
Users can search by various criteria, including different franchises and difficulty levels.

## Project Functionality

**Main features** included in the app:
- View all quizzes with search, filter, and sort options
- View all existing franchises in the system
- View all quizzes for a single franchise
- Complete a quiz with instant explanation after clicking the answer
- View statistics after completing a quiz
- View information about the app and its author

## Project usefulness

The project helps users test their knowledge of various movies, recall memorable moments, and more. 
This helps them stay engaged in the movie industry.
